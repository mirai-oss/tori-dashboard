# 貼替手順（a7pc）: 経営ダッシュボードの口コミタブを Supabase 直読みにする

所要 5 分。やることは「ファイルの中身を Apps Script に貼って、保存して、デプロイを更新する」だけです。

**用意するもの**: Chrome（Google にログイン済み）／このフォルダの `gas/Code.gs`

---

## 手順1: 新しいコードをコピーする
1. Finder で `Claude` → `tori-dashboard` → `gas` を開く。
2. `Code.gs` を **右クリック → このアプリケーションで開く → テキストエディット**。
3. 開いた画面で **⌘A（全部選ぶ）→ ⌘C（コピー）**。何も変えずに閉じる。

> 合図: 7,500 行くらいの長い文字がコピーされています。

## 手順2: Apps Script に貼る
1. Chrome で スプレッドシート「**【サーバー】ダッシュボード(v2・バージョン上限のため移行)**」を開く。
2. 上のメニュー「**拡張機能**」→「**Apps Script**」。
3. 左のファイル一覧で「**Code.gs**」をクリック（他のファイルは触らない）。
4. 右の編集画面の中をクリック → **⌘A → Delete → ⌘V**（古い中身を全部消して、新しい中身を貼る）。
5. **⌘S** で保存。

> 合図: 保存のあと、画面上に赤いエラーが出ない。
> 困ったとき: 「構文エラー」のような赤い文字が出たら、画面をそのまま見せてください。

## 手順3: デプロイを更新する（**「新しいデプロイ」は押さない**）
1. 右上の青い「**デプロイ**」→「**デプロイを管理**」。
2. 出てきた窓の右上の **鉛筆（編集）** をクリック。
3. 「バージョン」のプルダウンを「**新バージョン**」にする。
4. 説明の欄に `a7pc` と入れる。
5. 「**デプロイ**」→「**完了**」。

> 合図: 窓が閉じる。URL は前と同じまま（変わっていたら「新しいデプロイ」を押しています。押してしまったらそのまま私に教えてください）。

## 手順4: 私に「貼替した」と一言
私が本番の版（ping = a7pc）と、ダッシュボードの口コミタブの数字を確認します。

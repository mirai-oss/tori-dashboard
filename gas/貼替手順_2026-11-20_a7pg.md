# 貼替手順（a7pg）: PL への書き込みが重ならないようにする（PL整理 ①原因を止める）

所要 5 分。やることは「ファイルの中身を Apps Script に貼って、保存して、デプロイを更新する」だけです。

**用意するもの**: Chrome（Google にログイン済み）／このフォルダの `gas/Code.gs`（最新にしてから）

**何が変わるか**: PL のシートに書き込む 7 つの入口（MF 取込の確定／仕入れ移動の登録・取消・承認／スポット人件費の連携／銀行借入の連携／古い結合形式の掃除）に、「同時に 1 つしか書かない鍵」を付けます。月次 PL の内訳（補助科目）が別の行のものに入れ替わる原因を止めるためです。数字や画面は変わりません。

---

## 手順0: コードを最新にする
Claude に「a7pg を main に入れて」と言ってください。入ったら、手順1へ進みます。

## 手順1: 新しいコードをコピーする
1. Finder で `Claude` → `tori-dashboard` → `gas` を開く。
2. `Code.gs` を **右クリック → このアプリケーションで開く → テキストエディット**。
3. 開いた画面で **⌘A（全部選ぶ）→ ⌘C（コピー）**。何も変えずに閉じる。

## 手順2: Apps Script に貼る
1. Chrome で スプレッドシート「**【サーバー】ダッシュボード(v2・バージョン上限のため移行)**」を開く。
2. 上のメニュー「**拡張機能**」→「**Apps Script**」。
3. 左のファイル一覧で「**Code.gs**」をクリック（他のファイルは触らない）。
4. 右の編集画面の中をクリック → **⌘A → Delete → ⌘V**。
5. **⌘S** で保存。

> 合図: 保存のあと、画面上に赤いエラーが出ない。

## 手順3: デプロイを更新する（**「新しいデプロイ」は押さない**）
1. 右上の青い「**デプロイ**」→「**デプロイを管理**」。
2. 出てきた窓の右上の **鉛筆（編集）** をクリック。
3. 「バージョン」のプルダウンを「**新バージョン**」にする。
4. 説明の欄に `a7pg` と入れる。
5. 「**デプロイ**」→「**完了**」。

## 手順4: 私に「貼替した」と一言
私が本番の版（ping = `...-a7pg`）と、PL の書き込みの動きを確認します。
